# Лабораторная работа 2: Структура проекта 

## 1. Назначение проекта
Цель работы — упорядочить файлы, выстроить корректную структуру папок и убедиться, что код сохраняет работоспособность после перезапуска среды выполнения.

## 2. Состав проекта
- notebooks/lr01_runtime_order_goncharova.ipynb — готовый ноутбук, созданный в рамках первой лабораторной работы.
- data/sample_text.txt — исходный текстовый файл для проверки.
- data/mini_corpus.tsv — таблица с текстовыми карточками.
- `docs/version_log.md — журнал версий, в котором зафиксированы этапы работы и внесённые изменения.

## 3. Как запустить
1. Открыть Google Colab.
2. Загрузить ноутбук из папки notebooks.
3. Перенести файлы из папки data в сессию Colab, чтобы код мог к ним обратиться.

## 4. Проверка воспроизводимости
Среда была сброшена через **Restart runtime**, после чего все ячейки запущены заново командой **Run all**. Код выполнился без ошибок; проблема NameError больше не возникает.

## 5. Ограничения
Проект использует только базовый Python без дополнительных библиотек. Если не загрузить файлы данных в сессию, код завершится ошибкой — файлы не будут найдены.

## 6. История версий
Все изменения и сведения о версиях собраны в файле docs/version_log.md.

## 7. Критерий качества
Ключевой критерий качества проекта — портативность. Пути к данным заданы относительными адресами (например, ../data/), поэтому проект должен запускаться на другом компьютере без правки кода.
